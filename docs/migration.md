# Migration roadmap

- **Phase 0 — implemented:** external legacy orchestration.
- **Phase 1 — implemented:** hybrid DSH-backed engine; native tools only;
  legacy remains the default and the Veramux journal remains authoritative.
- **Phase 2 — future:** prove DSH-native workflow parity for deterministic
  controls before moving them into upstream primitives.
- **Phase 3 — future:** consider making the DSH-backed engine the default
  after parity evidence.
- **Programmatic — blocked:** requires a verified isolated OS boundary.

No dates are implied. A Web UI is architecture-ready/future integration only,
not part of this migration phase.
